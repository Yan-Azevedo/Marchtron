# Política de Privacidade — Marchtron

O Marchtron é um agente declarativo para Microsoft 365 Copilot voltado a esclarecer dúvidas sobre tecnologias Microsoft.

## Coleta e armazenamento de dados
O Marchtron **não coleta, não armazena e não compartilha dados pessoais**. Não há banco de dados, perfil de usuário ou persistência de conversas por parte do agente.

## Funcionamento
Ao receber uma pergunta, o agente consulta documentação pública oficial da Microsoft em tempo real, por meio de:
- **Microsoft Learn MCP Server** (público, sem autenticação)
- **Microsoft Release Communications MCP Server** (público, sem autenticação)

Nenhuma dessas fontes recebe dados pessoais do usuário além dos termos de busca necessários para localizar a documentação.

## Processamento
O processamento das conversas é realizado pela plataforma **Microsoft 365 Copilot**, sujeito às políticas de privacidade da Microsoft, fora do controle deste agente.
